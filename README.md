Online Job Portal System


An Online Job Portal System designed to connect job seekers with employers. This platform streamlines the recruitment process, enabling users to post jobs, search for openings, and manage applications efficiently.

🚀 Features

For Job Seekers
Register and create a professional profile.
Search for jobs based on filters like location, role, and company.
Apply to jobs directly and track application status.
For Employers
Register and create a company profile.
Post job openings with detailed descriptions and requirements.
View applications and manage job postings.
Admin Features
Manage users (job seekers and employers).
Monitor job postings and ensure platform compliance.
🛠️ Tech Stack
Frontend: HTML, CSS, JavaScript
Backend: PHP
Database: MySQL
Server: Apache (via XAMPP or similar)

php

Place the project folder in the htdocs directory (e.g., C:/xampp/htdocs/Online-Job-Portal-System).
Access the platform:

Navigate to http://localhost/Online-Job-Portal-System in your browser.
